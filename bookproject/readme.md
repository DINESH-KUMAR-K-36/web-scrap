# 📚 Web Scraping Project (Scrapy)

A professional web scraping project built using **Scrapy** framework.

This project demonstrates:

- Data extraction from websites
- Pagination handling
- Item pipelines
- SQLite database storage
- JSON/CSV export
- Proxy & User-Agent rotation (optional)
- Scrapy + Playwright integration (advanced)

---

## 🚀 Features

✔ Extracts structured data (title, price, rating / quotes etc.)  
✔ Handles pagination  
✔ Stores data into SQLite database  
✔ Exports to JSON / CSV  
✔ Supports middleware customization  
✔ Production-ready architecture
